# The Neuman manifesto

The principles that guide the development of Neuman.

1. **AI must serve the person using it, never the company that sold it.**
2. **People have the right to their own data.**
3. **People should own their own compute.**
4. **Open source is the future.**
5. **Neuman belongs to the open ecosystem it is built from, and always will.**
6. **AI should be custom, tailored to the person using it.**
7. **User interfaces should be intuitive.**
8. **Design and technical choices should be intentional.**
9. **Software architecture should be well thought out, and as simple as
   possible, but no simpler.**
10. **Only innovate when innovation is actually needed.**
